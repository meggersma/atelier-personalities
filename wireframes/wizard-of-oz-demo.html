About this demo

This is a working prototype of a feature we're considering for Atelier, the witness examination simulator. You're seeing how a post-session review would work if the lawyer could pick from multiple AI "partner twin" reviewers, each with a distinct critique style.

Scripted in this demo

  • The two cross-examination sessions (Hayes and Voss) are written transcripts, not from real practice
  • The witness state trajectories shown in the dashboard are illustrative
  • Session scores are hand-set to plausible values, not generated by a scoring model

Real

  • The partner-twin critique — comments, suggestions, suggested rewrites — is real LLM output, generated by conditioning Claude with each partner's persona description
  • The distinguishability between Sarah and David is what we want feedback on: do they read as different attorneys, or as the same content with different labels?
  • The flow (review session → see feedback → optionally swap reviewers → optionally compare) is what the production version would look like

Questions we'd love your reaction to

  • Does Sarah's voice sound like a real securities litigation partner?
  • Does David's voice sound meaningfully different from Sarah's?
  • Which view (dashboard or tracked changes) felt more useful?
  • Would you trust this kind of feedback for your own practice or a supervisee's?
  • What's missing?
Send one line of feedback — anything is useful.
